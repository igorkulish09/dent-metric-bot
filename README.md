# Telegram-бот для розрахунку кузовного ремонту авто

Бот приймає фото пошкодження (тріщина, вм'ятина, скол, подряпина тощо),
аналізує його через Claude Vision, або дозволяє ввести дані вручну —
і видає орієнтовний кошторис ремонту.

## Можливості

- 📸 Аналіз фото пошкодження через AI (Claude Vision) — автоматичне визначення
  типу і розміру пошкодження
- ✍️ Ручний ввід: марка, модель, рік випуску, тип і розмір пошкодження
- 🔧 Вибір додаткових робіт (полірування, ґрунтування, підбір кольору тощо)
- 💰 Розрахунок вартості з урахуванням класу авто (економ/стандарт/преміум)
  та віку авто
- 💾 Збереження всіх заявок у SQLite
- 📞 Запис на діагностику з передачею заявки адміністратору

## Встановлення

1. Встановіть Python 3.10+

2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```

3. Скопіюйте `.env.example` у `.env` і заповніть:
   ```bash
   cp .env.example .env
   ```
   - `BOT_TOKEN` — отримайте у [@BotFather](https://t.me/BotFather) в Telegram
     (команда `/newbot`)
   - `ANTHROPIC_API_KEY` — отримайте на [console.anthropic.com](https://console.anthropic.com)
   - `ADMIN_IDS` — ваш Telegram user ID (можна дізнатися через [@userinfobot](https://t.me/userinfobot))

4. Запустіть бота:
   ```bash
   python main.py
   ```

```
    └── calculation.py       # додаткові роботи, розрахунок, запис на СТО
```

## Налаштування прайсу під себе

Всі ціни і коефіцієнти знаходяться в **`price_data.py`**:

- `CAR_CLASSES` — які марки відносяться до економ/стандарт/преміум класу
  і коефіцієнт подорожчання деталей/фарби
- `DAMAGE_TYPES` — базові ціни за тип пошкодження
- `DAMAGE_SIZE` — коефіцієнт залежно від розміру (мале/середнє/велике)
- `EXTRA_WORKS` — додаткові послуги та їх фіксована ціна
- `year_coefficient()` — надбавка за вік авто

Формула:
```
вартість_основних_робіт = базова_ціна × коеф_розміру × коеф_класу_авто × коеф_віку
+ сума додаткових робіт
= загальна сума
```

## Хостинг (щоб бот працював 24/7)

Варіанти для деплою:
- **VPS** (DigitalOcean, Hetzner, тощо) — запустити через `systemd` або `screen`/`tmux`
- **Railway.app** / **Render.com** — безкоштовний старт, легкий деплой з GitHub
- **Docker** — можна обгорнути проєкт у контейнер (Dockerfile за потреби можу
  також підготувати)
