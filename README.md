# DentBot — Telegram-бот для розрахунку вартості видалення вм'ятин

Внутрішній інструмент для майстра/сервісу PDR: калькулятор вартості ремонту,
журнал замовлень, облік оплат і генерація акту виконаних робіт (PDF).

## Що вміє

- 🧮 **Розрахунок вартості** вм'ятини за параметрами: елемент кузова →
  технологія (без/з фарбування) → складність → матеріал панелі → клас авто →
  розмір (ширина/довжина, см). Ціна рахується автоматично за формулою
  `базова_ціна × коефіцієнти`.
- Кілька вм'ятин в одному замовленні (як в оригінальному застосунку).
- 📒 **Журнал** — активні замовлення (в роботі).
- 🕑 **Історія** — завершені замовлення.
- 💰 Облік оплати всередині бота (внесена сума / залишок) — не потрапляє
  в акт, лише для внутрішнього обліку.
- 📄 Автогенерація **акту виконаних робіт у PDF** з даними клієнта, авто,
  переліком послуг із розмірами та сумою — готовий відправити клієнту.
  Шрифт із підтримкою кирилиці **вбудований прямо в код** (`font_data.py`,
  base64) — працює на будь-якій ОС і не залежить від того, чи скопіювали
  папку `fonts/`.
- 🗑 Видалення окремих вм'ятин або цілого замовлення.
- 📅 **Календар запису на ремонт** — обираєш дату тицяючи на календар,
  потім час (швидкі кнопки 9:00–18:00 або ввести вручну). Розклад по
  днях доступний окремо в меню "📅 Розклад".
- ⏰ **Нагадування** — бот сам пише майстру за добу і за годину до запису.
- Обмеження доступу за списком Telegram user_id (тільки ти й твої майстри).

## Встановлення

1. Постав Python 3.10+.
2. Встанови залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Створи бота через [@BotFather](https://t.me/BotFather), отримай токен.
4. Скопіюй `.env.example` у `.env` і заповни:
   ```bash
   cp .env.example .env
   ```
   - `BOT_TOKEN` — токен від BotFather
   - `ALLOWED_USER_IDS` — твій Telegram ID і ID майстрів через кому
     (дізнатись ID можна в бота [@userinfobot](https://t.me/userinfobot)).
     Якщо залишити порожнім — бот буде доступний усім, хто його знайде.
   - `COMPANY_NAME`, `COMPANY_TAX_ID`, `COMPANY_ADDRESS`, `COMPANY_PHONE` —
     підставляються в акт як дані виконавця.

5. Запусти:
   ```bash
   python main.py
   ```

Бот працює через polling — має бути постійно запущений (на своєму ПК,
VPS або, наприклад, через `systemd`/`screen`/`tmux`, щоб не зупинявся).

## Матеріали панелі

Доступні: Сталь, Алюміній, Пластмаса (коефіцієнти — у `pricing.py`).

## Самоперевірка при старті

`main.py` при запуску сам перевіряє, що всі файли проєкту синхронізовані
(наприклад, чи є в `database.py` потрібні функції, чи завантажився шрифт
для PDF). Якщо щось не так — бот не стартує наосліп, а одразу пише в
консоль, чого саме бракує і що оновити. Якщо бачиш таке повідомлення —
найнадійніше розпакувати останній архів проєкту повністю поверх поточної
папки, а не копіювати файли по одному.

## Налаштування цін

Усі базові ціни та коефіцієнти — у файлі `pricing.py`:

```python
ELEMENTS = {
    "front_bumper": ("Передній бампер", 3500),
    ...
}
TECHNOLOGY = {"no_paint": ("Без фарбування", 1.0), "with_paint": ("З фарбуванням", 1.7)}
COMPLEXITY = {"medium": (..., 1.0), "high": (..., 1.5)}
MATERIAL = {"steel": (..., 1.0), "aluminum": (..., 1.4)}
CAR_CLASS = {"standard": (..., 1.0), "premium": (..., 1.3)}
```

Постав свої реальні ціни й коефіцієнти — після зміни файлу достатньо
перезапустити бота.

## Структура проєкту

```
dentbot/
├── main.py            # запуск бота, підключення роутерів
├── config.py           # читання .env
├── database.py         # SQLite: замовлення та вм'ятини
├── pricing.py           # ціни й коефіцієнти (редагуй тут)
├── pdf_generator.py     # генерація акту (reportlab)
├── keyboards.py         # клавіатури, календар
├── states.py            # FSM-стани
├── access.py            # обмеження доступу за user_id
├── scheduler.py          # фоновий цикл нагадувань про записи
├── fonts/                # шрифт для кирилиці в PDF (DejaVu Sans)
└── handlers/
    ├── start.py          # /start, головне меню
    ├── calculator.py     # розрахунок вм'ятини + створення замовлення
    ├── journal.py         # журнал / історія
    ├── order_detail.py    # акт, завершення, видалення
    └── appointments.py     # календар запису + перегляд розкладу
```

## Дані

Все зберігається в SQLite-файлі `dentbot.sqlite3` (створюється автоматично
при першому запуску). Для бекапу достатньо скопіювати цей файл.

## Можливі наступні кроки

- Прив'язати кілька майстрів до однієї спільної бази замовлень (зараз
  кожен майстер бачить лише свої замовлення — `master_id`).
- Додати фотографії вм'ятин до замовлення.
- Статистика/звіти за період (сума виручки, кількість замовлень).
- Розгортання на сервері через webhook замість polling.

Скажи, якщо щось із цього треба додати — допоможу.
